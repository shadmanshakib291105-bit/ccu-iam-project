# CCU IAM Project – Project Plan

This repository holds the project plan for **Assessment 3 (Group): Project 2 – Identity and Access Management (IAM) System Deployment for Cybersecurity Enhancement**.

The client is Coastal Credit Union (a fictional APRA-regulated mutual bank used as the case scenario).

We use GitHub for version control and configuration management of all project documents, as described in Section 11 of the report.

## What is in this repository

| Folder or file | What it contains |
| --- | --- |
| docs/plan/ | The project plan report (Word), schedule, Gantt chart, risk register, risk matrix, change log, change request process |
| docs/design/ | Work breakdown structure (WBS) |
| docs/meetings/ | Meeting minutes |
| .github/ISSUE_TEMPLATE/ | Forms for logging risks, issues and change requests |
| .github/pull_request_template.md | Checklist used when reviewing changes |
| CONTRIBUTING.md | Our rules for making changes |
| CHANGELOG.md | Summary of each approved version (baseline) |

## How we track work

- **Issues** are our risk log, issue log and change request log (labels: `risk`, `issue`, `change-request`).
- **Branches and pull requests** are used to change documents, so every change is reviewed by another member.
- **Releases (tags)** mark approved baselines, for example `v1.0`.
